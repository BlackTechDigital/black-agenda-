# BLACK AGENDA — MVP

Aplicativo demonstrativo estático para múltiplos tipos de negócios.

## Como testar
Abra `index.html` em um navegador moderno ou publique os arquivos na raiz de um repositório GitHub Pages.

## Recursos
- Agendamentos por data, serviço e profissional/recurso
- Bloqueio de conflitos de horários para o mesmo profissional
- Cadastro de serviços, duração e preços
- Cancelamento e exclusão de agendamentos
- Dashboard, filtro por data, horário de expediente
- Exportação/importação de backup JSON
- Layout responsivo e persistência local via localStorage

## Limitações importantes
Este MVP não possui backend, autenticação, multiusuário, reservas públicas, pagamentos ou notificações. Os dados ficam apenas no navegador local, podem ser apagados e não são apropriados para produção ou dados pessoais sensíveis. O indicador de receita é uma previsão dos agendamentos confirmados, não pagamentos recebidos. Testar extensivamente antes de qualquer uso real.
